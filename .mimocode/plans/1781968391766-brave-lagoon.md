## Redundancies Found

### 1. Skill Creation (HIGH redundancy)
- `write-a-skill` (~/.agents/skills)
- `skill-creator` (~/.codex/skills/.system)

Both create agent skills. Consolidate to one.

### 2. Skill Discovery (MEDIUM redundancy)
- `find-skills` (~/.agents/skills)
- `skill-installer` (~/.codex/skills/.system)

Overlapping purpose. `find-skills` is more user-facing discovery; `skill-installer` is the actual installer.

### 3. Grilling (LOW redundancy)
- `grill-me` — basic interview
- `grill-with-docs` — interview + documentation awareness

Near-identical, but `grill-with-docs` adds value. Consider merging or keeping both if both are used.

### 4. Empty/Missing Skills
- `codex-primary-runtime` — empty directory on disk, no SKILL.md, NOT in system prompt
- `open-pencil` — in .skill-lock.json but missing from disk entirely

### 5. Browser Automation Overlap
- `agent-browser` skill (~/.codex/skills)
- `browser` plugin (~/.codex/plugins/cache/openai-bundled)

Both handle browser automation. Different tools (skill vs plugin).

### 6. Document Handling Overlap
- `doc` skill (~/.codex/skills)
- `documents` plugin (~/.codex/plugins/cache/openai-primary-runtime)

Both handle documents. Different scope (DOCX vs general).
